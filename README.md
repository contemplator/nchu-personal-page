# 國立中興大學 人工智慧與資訊安全課程 - 個人網頁作業

> 本專案為國立中興大學（NCHU）**「人工智慧與資訊安全」** 課程之個人網頁作業，用於展示個人學經歷、技術專長、課程作業成果與專案內容。

---

## 📌 專案簡介 (Project Overview)

本網頁旨在結合課程所學之 **人工智慧 (AI)** 與 **資訊安全 (Information Security)** 概念，設計並建立一個現代化、響應式（Responsive）的個人展示網頁。

### 🌟 核心特色
- **現代化介面設計**：乾淨俐落的 UI/UX 設計與響應式排版（支援電腦與手機版面）。
- **個人經歷與技能展示**：包含簡介、學歷背景、專業技能（AI / 資安 / 軟體開發）。
- **課程專案與作業展示**：整理課程中的各項作業、實作與研究專案。
- **資安與最佳實踐**：注重前端安全（如避免 XSS、妥善設定資源連結與安全標頭等）。

## 🚀 快速開始 (Getting Started)

### 1. 本地端預覽 (Local Setup)

1. 複製（Clone）此專案至本地端：
   ```bash
   git clone https://github.com/contemplator/nchu-personal-page.git
   ```
2. 進入專案資料夾：
   ```bash
   cd nchu-personal-page
   ```
3. 直接使用瀏覽器開啟 `index.html`，或使用 VS Code 的 **Live Server** 擴充套件啟動本地伺服器預覽。

### 2. GitHub Pages 線上佈署

1. 將專案推送到 GitHub：
   ```bash
   git add .
   git commit -m "feat: init personal page"
   git push origin main
   ```
2. 至 GitHub 倉庫的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下的 **Branch** 選擇 `main` 分支並儲存。
4. 稍等片刻即可透過 `https://contemplator.github.io/nchu-personal-page/` 瀏覽線上網頁。
